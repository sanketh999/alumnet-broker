# PawCircle — Interactive Prototype

India's first shared-care platform for multi-generational pet-owning households.

## 🐾 What is this?

A fully interactive mobile prototype of PawCircle — a pet care app built for Indian joint families where care is shared across multiple caregivers (a retired parent at home, a working adult child, a weekend helper).

## 🚀 Deploy on Vercel

1. Push this repo to GitHub
2. Go to [vercel.com/new](https://vercel.com/new)
3. Import your GitHub repo
4. Vercel auto-detects Vite — click **Deploy**
5. Your prototype is live at `your-project.vercel.app`

## 🛠 Local Development

```bash
npm install
npm run dev
```

Opens at `http://localhost:5173`

## 📱 Features in this Prototype

- **Caregiver Switching** — Ashatai, Aditya, Priya
- **Multi-pet Dashboard** — Bruno (dog), Mia (cat), Rio (parrot)
- **Interactive Care Plans** — Tap checkboxes to mark tasks done
- **Vet Booking** — Day/time picker, specialist selection, confirmation
- **Vaccination Tracker** — Filter by pet, add new records via form
- **Hostel Booking** — Expandable cards, full booking form with pricing
- **Playdate Scheduling** — Fillable form to schedule new playdates
- **Activity Feed** — Timeline of all caregiver actions
- **Expense Tracker** — Monthly breakdown by category and caregiver
- **Pet Profiles** — Weight charts, allergies, vaccination history
- **PawCircle Reels** — Scrollable video feed with search & filters
- **Profile & Settings** — Sub-screens for pets, household, expenses
